# 果果合合 · 水果 2048

一个无需安装依赖、可在手机和电脑浏览器直接游玩的水果合成小游戏。相同水果相撞即可合成下一种水果，目标是合成西瓜并冲击高分。

## 操作方式

- 手机/平板：在棋盘上上下左右滑动。棋盘会拦截游戏区域内的浏览器滚动手势；合并时支持轻微触觉反馈（设备和浏览器支持时）。
- 电脑：使用方向键移动，按 `U` 撤销。
- 点击“撤销”回退一步，点击“新游戏”重新开始。

## 本地运行

直接用浏览器打开 `index.html`，无需构建步骤或额外依赖。

## 发布到 GitHub Pages

把本仓库推送到 GitHub 后，在仓库 **Settings → Pages** 中选择从 `main` 分支的根目录发布。GitHub Pages 会以根目录的 `index.html` 作为首页。
